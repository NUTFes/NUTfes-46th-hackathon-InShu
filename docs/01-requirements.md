# 隠酒（インシュ） 要件定義（作成中）

## 目的
技大祭の公式広報が写真を公開する前に、広報NGの写り込みを見落とさず、すぐ直せるようにする。見せ方はネタ（お酒がジュースに化ける）だが、中身は公式広報が実際に使える品質にする。

## 背景・課題
- チェックが人の目頼み：大量の写真を一枚ずつ見ていて、負担が大きく見落としが出る
- 何がアウトかの基準が曖昧：人によって判断が違う
- 気づかないうちにお酒の写真が入り込んでいる：背景の缶やグラスなど、撮った本人も気付かない写り込みがある

## コンセプト
**広報NGを見つけて、お酒はジュースに化かす、公式広報の写真チェック係。**
- 写真をまとめて入れると、広報NGの写り込みを見つけ、炎上リスクとして示す
- お酒は AI でジュースに置き換える（ネタの見せ場）。ビフォーアフターで見比べられる
- お酒以外の NG（タバコ・個人情報など）は場所を示し、ぼかせる
- 何が NG かの基準を1か所に書き、判定がその基準に沿うようにする

## ユーザーと権限
| ユーザー | 説明 | ログイン |
|---|---|---|
| 広報担当 | 写真をチェック・加工して、公開用の画像を持ち帰る | Slack ログイン＋広報担当に登録済み |
| 広報責任者 | 広報担当の機能に加えて、広報NGの基準と広報担当の登録を管理する | 同上＋責任者に登録済み |
| 隠酒（システム） | 写真を判定し、置き換え・ぼかしを行う | - |

## 要求
1. 広報担当は、写真を1回に20枚までまとめて入れられる
2. 写真ごとに、広報NGの写り込みを見つけ、項目・場所（枠）・理由を示す
3. 写真ごとに炎上リスクを点数で示し、一覧でリスクの高い順に並べられる
4. お酒の写り込みは、AI でジュースに置き換えられる。ジュースの種類を選べる
5. お酒以外の NG は、場所を示し、ボタンでぼかせる
6. 加工前と加工後をビフォーアフターで見比べられる
7. 加工した画像をダウンロードできる（1枚ずつ・まとめて）
8. 処理した写真はギャラリーに残る。加工後の画像は広報担当の全員が見られる。元画像（加工前）は処理した本人だけが見られる
9. 元画像と加工後の画像は、アップロードから30日で自動で消す
10. 広報責任者は、広報NGの項目と説明（基準）を画面で編集できる。判定はその基準に沿って行う
11. 判定は見落としを減らす補助であり、最終判断は人が行う。判定結果に「問題なし」と出ても公開の責任は広報にある旨を画面に示す

## 状態の流れ（写真）
- アップロード済み → 判定中 → 判定済み（NG なし／NG あり）→ 加工済み → 期限切れ（自動削除）
- 判定に失敗したものは「判定失敗」とし、やり直せる

## 制約・前提
- Web で作る（ハッカソンのレギュレーション）
- 写真には人の顔が写る。写真は Gemini に送って判定・加工する（広報担当に周知する）
- 実際の問題行為（未成年の飲酒など）を隠すためには使わない。あくまで広報上の配慮として使う（運用ルール）
- 技術は良良タイムズと揃える（Next.js on Cloudflare Workers、D1、R2、Slack ログイン、Gemini）
- 締切：11/24 成果発表

## 決定（11/16）
- 目的：ネタだけど実用も
- 使い手：技大祭の公式広報（Slack ログイン）
- 判定の範囲：広報NG全般。置き換えるのはお酒だけ、他はぼかせる
- 基準：広報責任者が画面で編集する
- ギャラリー：加工後の画像は広報担当の全員が見られる。元画像は処理した本人だけ
- 画像の保存：アップロードから30日で自動削除
- 1回の上限：20枚
- 広報NGの初期項目：お酒・タバコ／個人情報（名札・学生証・ナンバープレート・画面）／他社のロゴ・著作物／危険・不適切な行為
- 置き換え：AI 画像編集（Gemini）
